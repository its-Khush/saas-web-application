SaaS Web Application

A full-stack SaaS web application built using modern web technologies.

Project Structure

frontend/ — Frontend application

backend/ — Backend application and API services

Technologies Used

Frontend: React, JavaScript, Vite

Backend: Node.js, Express.js

Other: REST APIs and email integration using Resend

Getting Started

Prerequisites

Node.js and npm

Required environment variables for the backend

Installation

Install dependencies separately in the frontend and backend directories:

cd frontend/saas-frontend-main
npm install

cd backend/saas-backend-main
npm install

Configure the required environment variables in a local .env file before running the application.

Security

Do not commit API keys, passwords, or .env files to version control.
